# fredrikhaugen/tap

Homebrew formulae by Fredrik Haugen.

```sh
brew install fredrikhaugen/tap/wake
```

This taps fredrikhaugen/tap and trusts only the wake formula. After that, `brew upgrade wake` and `brew uninstall wake` work by the short name.

- [`wake`](https://github.com/FredrikHaugen/wake): keep your Mac awake with a countdown that fills the terminal
